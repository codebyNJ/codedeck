Privacy

Repobox is a window onto files you already have. It doesn't run agents, call an AI, or send anything anywhere.

  • Reads agent history files; never edits or deletes them
  • No account and no sign-in

Questions

Good to know.

What is Repobox?

Repobox is a Mac app that finds every code repo on your computer and lists the Claude Code, Codex and OpenCode conversations that belong to each one. From there you can open the project in your editor or resume any session in one click.

How do I resume an old Claude Code session?

Find the session in Repobox (or press ⌘K and type part of its name) and press Resume. Repobox opens Terminal in that project's folder and runs claude --resume with the session's ID, so the full conversation comes back.

Which coding agents does it support?

Claude Code, OpenAI Codex CLI and OpenCode. Each one can be turned off in Settings.

Does Repobox upload my code or chats?

No. It only reads files that are already on your Mac and never sends your code or conversations anywhere. There's no account and no AI inside.

Will it change my agent history?

No. Repobox only reads the history folders. Resuming uses each agent's own command, so the agent itself does the work.

Does it work on Windows or Linux?

Not yet. Repobox is a native Mac app for macOS 13 or later.

How do I say it?

Like it's spelled: “repo box”. A box for your repos.
